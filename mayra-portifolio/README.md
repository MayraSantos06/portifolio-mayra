# Portfólio Profissional

## 1. Descrição do Projeto

O Portfólio Profissional é uma aplicação web desenvolvida com o objetivo de apresentar minha trajetória acadêmica, habilidades técnicas, projetos desenvolvidos e experiências na área de tecnologia.

O site busca proporcionar uma apresentação profissional, organizada, acessível e responsiva, permitindo que visitantes conheçam meu perfil e entrem em contato comigo.

## 2. Objetivos

- Apresentar minha formação e meus interesses profissionais.
- Exibir projetos desenvolvidos durante minha trajetória acadêmica e prática.
- Organizar experiências e atividades relevantes na área de tecnologia.
- Disponibilizar canais de contato profissionais.
- Aplicar conhecimentos de desenvolvimento web, organização de código e publicação de aplicações.

## 3. Funcionalidades Previstas

- **Sobre Mim:** apresentação pessoal em português e inglês.
- **Projetos:** linha do tempo com nome, descrição, tecnologias, link do GitHub e imagens ou GIFs dos projetos.
- **Experiências:** apresentação de experiências profissionais, acadêmicas e atividades técnicas.
- **Contato:** links para e-mail, WhatsApp e LinkedIn, além de formulário para envio de mensagens.
- **Responsividade:** adaptação da interface a computadores, tablets e celulares.

## 6. Instalação e Execução

### Pré-requisitos

- Node.js
- npm
- Git (para versionamento)

### Instalação

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Entre na pasta do projeto:

```bash
cd portfolio-profissional
```

Instale as dependências:

```bash
npm install
```

Execute o ambiente de desenvolvimento:

```bash
npm run dev
```

Acesse no navegador:

http://localhost:3000
