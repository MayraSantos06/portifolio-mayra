# Portfólio Profissional — Mayra

## 1. Descrição do Projeto

O Portfólio Profissional é uma aplicação web desenvolvida com o objetivo de apresentar minha trajetória acadêmica, habilidades, projetos e experiências na área de Engenharia de Software.

O site terá uma interface moderna, responsiva e acessível, permitindo que visitantes conheçam meu perfil profissional e encontrem formas de entrar em contato comigo.

## 2. Objetivos

- Apresentar minha formação e meus interesses profissionais.
- Divulgar projetos acadêmicos e pessoais.
- Demonstrar conhecimentos em desenvolvimento de software.
- Disponibilizar canais de contato profissional.
- Aplicar conhecimentos de desenvolvimento e integração de aplicações web.

## 3. Funcionalidades Previstas

- **Sobre Mim:** apresentação pessoal em português e inglês.
- **Projetos:** linha do tempo com descrição, tecnologias, repositório GitHub e imagens ou GIFs.
- **Experiências:** apresentação de experiências profissionais, acadêmicas e atividades técnicas.
- **Contato:** links para e-mail, WhatsApp e LinkedIn, além de formulário para envio de mensagens.
- **Responsividade:** adaptação do layout a computadores, tablets e celulares.

## 4. Tecnologias

- React
- TypeScript
- Vite
- CSS
- ESLint
- Git e GitHub
- Vercel (hospedagem planejada)

## 5. Instalação e Execução

### Pré-requisitos

- Node.js
- npm

### Instalação

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Entre na pasta do projeto:

```bash
cd mayra-portifolio
```

Instale as dependências:

```bash
npm install
```

Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

Acesse o endereço informado no terminal, normalmente:

http://localhost:5173/

## 6. Estrutura do Projeto

O projeto utiliza Vite para executar o ambiente de desenvolvimento e React com TypeScript para construir a interface.

- `src/`: código-fonte da aplicação.
- `src/assets/`: recursos utilizados pela interface.
- `public/`: arquivos estáticos.
- `package.json`: dependências e scripts do projeto.
- `vite.config.ts`: configuração do Vite.
